# Cipher

An intelligent AI Voice Assistant for Ubuntu.

## Features

- Offline AI (Ollama)
- Online AI (Gemini)
- Google Speech Recognition
- Whisper Fallback
- Memory
- Browser Control
- Application Control
- Camera
- OCR
- Face Recognition
- Screen Reader
- System Monitor

## Requirements

Python 3.12+

Ubuntu 24.04

## Run

```bash
python main.py
```
